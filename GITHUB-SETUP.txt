MK Movies v2.10.1 Named Resumable Downloads GitHub Setup
================================

1. Create a GitHub repository and upload the CONTENTS of this ZIP to the repository root.
2. Do not upload the private signing-backup ZIP or any .jks file to the repository.
3. When updating the same repository, keep the existing Actions secrets; do not add them again.
4. Only a new repository needs these three secrets:
   - KB_KEYSTORE_BASE64
   - KB_KEYSTORE_PASSWORD
   - KB_KEY_ALIAS
   - KB_KEY_PASSWORD
   These names match the existing secrets in the KB Movies repository.
5. Open Actions > Build MK Movies v2.10.1 Named Resumable Downloads APK/AAB > Run workflow.
6. Download mk-movies-release-apk for direct installation.
7. Download mk-movies-release-aab for Google Play Console.

The workflow will reject any signing key that does not match Google Play's expected SHA-1.
The AAB output is named MK-Movies-v2.10.1-play-console.aab.
